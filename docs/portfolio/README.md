# RepoDoctor — 給 vibe coder 的程式健檢醫生

網站：https://repodoctor-psi.vercel.app

## 一句話介紹

用 AI 寫程式的人越來越多，但程式寫出來之後藏了什麼危險，多數人看不出來。
RepoDoctor 連上 GitHub，用中文白話告訴你專案哪裡有問題，並給一段可以直接貼給 Claude Code 的修復指令。

## 短版（作品卡片用，約 80 字）

RepoDoctor 是給 vibe coder 的程式健檢服務。連上 GitHub、選一個專案，幾分鐘內用繁體中文白話列出金鑰外洩、資料表沒上鎖、頁面沒登入檢查等問題，每個問題附一段可以直接貼給 AI 的修復指令。

## 長版（作品介紹頁用）

**要解決的問題**
用 AI 生程式的門檻已經很低，真正讓新手卡住的是程式生出來之後：金鑰被推上 GitHub、資料庫沒有權限控管、同一個功能被 AI 寫了好幾份，而且自己看不出來，也不知道怎麼叫 AI 修。

**我做了什麼**
- **健檢引擎**：先用規則掃描抓出「確定的問題」（金鑰外洩、Supabase 資料表沒開 RLS、專案衛生），再把需要理解程式的部分交給 Claude 分析（登入與權限、重複程式、專案規範和程式不一致），兼顧準確度與 AI 成本。
- **白話報告與修復指令**：每個問題都有白話說明、為什麼危險，以及一段寫好的修復指令（要改哪裡、不能動什麼、怎麼驗證），一鍵複製交給 AI。
- **陪你改善，不只是健檢**：重新健檢時顯示「上次以來修好了哪些」，並依最弱的類別給出改善方向與可以寫進 CLAUDE.md 的規則，讓 AI 以後不再犯同樣的錯。
- **資安與隱私**：GitHub App 只申請唯讀權限，只看使用者勾選的專案；程式碼下載到臨時機器、健檢完立刻刪除；報告中的金鑰只保留前 4 碼；送給 AI 前所有疑似金鑰都先遮罩，送出前再檢查一次；使用者可以一鍵刪除自己的所有資料。

**技術架構**
- 前端：Next.js（App Router）＋ TypeScript ＋ Tailwind CSS，部署在 Vercel
- 資料庫與登入：Supabase（Postgres、GitHub OAuth、Realtime 即時掃描進度），每張資料表都開 Row Level Security，並用測試驗證越權存取會被擋下
- 健檢主機：Python，透過 GitHub App 唯讀淺層 clone；目前以 GitHub Actions 按需喚醒執行（Supabase trigger 觸發），零主機費用
- AI 分析：Claude API（依任務選用不同模型控制成本），每次健檢記錄 token 用量與台幣成本

**亮點數字**
- 用自己的 16 個實際專案驗證健檢準確度，抓出真實外洩的金鑰
- 健檢從按下按鈕到出報告約 1 分鐘
- 規則掃描零成本；開啟 AI 分析時每次約台幣 1–7 元
